# Alzheimer’s Disease Data Mining Project

---

## Project Description
Alzheimer’s disease is a progressive neurological condition that affects memory, thinking, and behavior. This project focuses on analyzing an Alzheimer’s Disease dataset containing demographic, lifestyle, medical, clinical, cognitive, and behavioral information about patients.

The project aims to apply data mining techniques to better understand patterns within the data. Classification will be used to distinguish between patients diagnosed with Alzheimer’s disease and those who are not diagnosed, while clustering will be used to identify groups of patients who share similar characteristics.

---

## Project Motivation
Alzheimer’s disease is an important health problem because it can significantly affect a person’s independence and quality of life. Analyzing patient data can help reveal patterns and characteristics that may be associated with the disease.

We chose this dataset because it contains a wide range of patient-related factors, including demographic information, lifestyle habits, medical history, clinical measurements, cognitive assessments, and symptoms. This makes it suitable for applying both classification and clustering techniques and allows us to explore how different patient characteristics may relate to Alzheimer’s disease.
